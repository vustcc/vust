# vust 仓库文档索引

## 组织级文档

组织级共享文档由 [vust-docs](https://github.com/vustcc/vust-docs) 仓库统一维护：

- [文档索引](https://github.com/vustcc/vust-docs#readme)：VUST 组织级文档入口。
- [architecture](https://github.com/vustcc/vust-docs/tree/main/architecture)：系统架构、Crate 边界、分布式模型。
- [standards](https://github.com/vustcc/vust-docs/tree/main/standards)：主题、运行环境、部署、认证、日志、WebSocket 等标准规范。
- [api](https://github.com/vustcc/vust-docs/tree/main/api)：API 设计规范、契约、接口目录和治理工作台。
- [suites](https://github.com/vustcc/vust-docs/tree/main/suites)：Compose 套件中心与套件开发规范。
- [simulation](https://github.com/vustcc/vust-docs/tree/main/simulation)：协议仿真、PCAP、规则库升级与兼容契约。
- [operations](https://github.com/vustcc/vust-docs/tree/main/operations)：运行时协议、跨 NAT、在线升级。
